Cloud multiplayer preview for Joey the Passion. Includes the native companion and its configured cloud endpoint; no original game files are distributed.

This preview is published only after the live cloud service and native transport checks pass: room creation/discovery, two-player joins, full-room rejection, isolated relay traffic, player IDs, idle connections and disconnect handling. A complete duel in the original game is still unverified.

Close the game, read the included README, and copy the two companion files beside the supported joey_pc.exe. Do not overwrite an existing dinput.dll from another mod.
