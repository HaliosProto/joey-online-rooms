JOEY THE PASSION + ONLINE MULTIPLAYER

This package contains the supplied game files and the configured multiplayer
preview together. It includes the public cloud lobby address.

PLAY
1. Extract the entire ZIP. Keep all files together in the extracted game folder.
2. Run joey_pc.exe.
3. Open the two-player/LAN multiplayer option and choose Online rooms as the
   connection provider.
4. Create a room, or select a room another player has created and join it.

Each friend should download and extract the same package on their Windows PC.
Each duel supports two players. No GameRanger, lobby account, VPN client, or
router port forwarding is required by the multiplayer implementation.

The companion requires Windows 8 or newer. The original game's requirements
and notices are included in ReadMe_Joey.html. This ZIP bundles the available
game folder; it is not the original disc installer.

PREVIEW STATUS
The cloud service and native connection checks passed, including public room
discovery, joining, player identities, capacity, session settings, binary data
exchange in both directions, idle connections and disconnect cleanup.
A complete duel inside the original game and its rendered menus remain
unverified. Some screens may retain their original LAN wording.

The cloud service uses free hosting allowances. Reaching a free quota can
interrupt online play until it resets.

FILES
dinput.dll and joey-online.ini add multiplayer. The original game executable
and data archives are unchanged. SHA256SUMS.txt lists the checksums of the
included files. The creator's machine-specific installation record is omitted.
