Full game files bundled with the configured online multiplayer preview.

Download **Joey-the-Passion-Online-Full-Game.zip**, extract it completely, and run **joey_pc.exe** from the extracted game folder. The multiplayer companion and cloud lobby address are already included. See **README-PLAY-ONLINE.txt** in the package for room creation and joining.

The package includes the supplied game folder, its original readme, the multiplayer files and file checksums. It is not the original disc installer. The machine-specific maintenance record is omitted.

Cloud and native connection tests passed. A complete duel in the original game and its rendered menus remain unverified, so this release is labelled a preview.
