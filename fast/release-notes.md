**Separate experiment; this is not the original Joey the Passion game.** The requested full game, including Joey AI and progression, is at https://haliosproto.github.io/joey-online-rooms/. Earlier website links now point there.

Joey Fast runs a dedicated duel engine directly on your device, with a new touch interface. It removes the Windows emulator used by the earlier mobile preview.

- **iPhone / iPad:** Open https://haliosproto.github.io/joey-online-rooms/fast/ in Safari, then Share -> Add to Home Screen.
- **Android / computers:** Open the same link. The existing Android launcher opens the updated site too.
- Both friends use **Joey Fast**. Create a room or join a visible room, then tap a card to inspect it and choose a move. The host goes first.
- Build and save a deck on your device, or use the supplied starter deck. Practice lets you control both sides on one device.
- The original card pool and artwork are retained, with alternate artwork grouped by the engine's card IDs. The classic five-zone field uses current effect scripts. This is a new client, with some ruling differences from the original executable.
- Original Windows/Mac downloads and the old mobile compatibility version remain available. Original campaign progress and saved collections are separate.
- This is a preview. Cloud browser checks do not replace physical-phone testing or qualification of every card interaction. Keep the app open during an online duel; leaving closes the room.

The existing free cloud service relays rooms. No PC server or paid billing is required. The device hosting a duel runs its rules engine; there is no remote game streaming.
