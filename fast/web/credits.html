The source of this client, its build scripts and modifications is available in the public source repository. This client is licensed under AGPL version 3 or later.

This is a new client using a classic five-zone field and current effect scripts. It does not reproduce every original-game ruling, campaign, voice sequence or saved collection. Both players use Joey Fast; existing compatibility releases remain separate.
