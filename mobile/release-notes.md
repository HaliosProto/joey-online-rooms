Mobile compatibility preview for the original Yu-Gi-Oh! Power of Chaos: Joey the Passion game, using the same public rooms as Windows and Mac.

- **iPhone / iPad:** Open https://haliosproto.github.io/joey-online-rooms/ in Safari, then Share → Add to Home Screen. Launch the new icon and download the game. No App Store listing or weekly signing is needed.
- **Android:** Download Joey-Online-Android.apk below and allow installation from your browser when Android asks. Open Joey Online and download the game. You can also use the Home Screen web app instead of the APK.
- First game download: approximately 573 MB. Use Wi-Fi, keep the app open and allow several minutes for the first startup. Game processing runs on your device; no PC host is needed.
- Tap to click, drag cards, use Right click for the next tap, Back for Escape, Name to type in a selected game field. Rotate to landscape.
- **Online play:** Duel Mode -> 2-PLAYER DUEL -> Data from your PC. Confirm your name with the in-game OK lever; select Host to create a room or Guest to find one, then confirm with OK.
- Saves stay in this app/browser on this device. Save inside the game and export a Save backup before clearing storage or uninstalling.

The signed APK is a small launcher for the locally executed browser game; it downloads the game on first use. Existing Windows and Mac downloads remain available.

This is a preview. Touch navigation through the original Host screen, room creation and public listing passed in Chromium and WebKit. Native room joining and binary relay inside the browser emulator also passed cloud tests. Two original game instances also pass Guest discovery and joining, reaching the rock-paper-scissors screen together. Physical phones, complete duels, audio quality and real-game save/load still need qualification. See TESTING.md for exact checks. Free service limits can interrupt availability; no paid billing is enabled.

Runtime: BoxedWine (GPL 2 or later) and Wine (LGPL 2.1 or later). The site credits link to the exact source revisions, build patches and license notices. Original game and artwork notices are retained.
