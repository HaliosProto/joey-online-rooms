Install on iPhone or Android

iPhone / iPad: Open this page in Safari, tap Share, then Add to Home Screen. Launch the new icon.

Android: Install the Android APK, or use your browser’s Install app / Add to Home screen option.

Controls, saves & preview status

Turn your phone sideways. If a demonstration is playing, tap once to return to the menu. Tap to click, drag to move cards. Use Right click for the next tap, Back for Escape, and tap the game’s buttons to confirm. Use Name to type in game text fields.

Choose Duel Mode, then the network option to create a room or join a friend. Internet is required for rooms.

Saves stay on this device. Save inside the game, then use Save backup to export a copy before clearing browser data. Closing the game during a duel disconnects you.

This preview runs the original Windows game on your device. First startup can take several minutes. Phone performance, audio and complete duels still need device testing.
