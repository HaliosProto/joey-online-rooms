Nothing to install. Your browser loads the game files automatically. The first load is large and can take several minutes; use Wi-Fi and keep this tab open.

Playing on a computer or phone

Computer: Open this page in a current Chrome, Edge or Safari browser and press Play game. Use the mouse and keyboard normally.

Phone / tablet: Open this same page in Safari or Chrome. Turn the phone sideways and use touch controls. Adding this page to the Home Screen is optional. The original game can run slowly on phones.

Controls, saves & online play

Tap or click to select, drag to move cards. If a demonstration is playing, tap once to return to the menu. Use Right click for the next tap, Back for Escape, and the game's own buttons or OK lever to confirm. Use Name to type into selected game text fields.

For Joey's AI, choose Duel Mode, then Single Duel or Match Duel. For friends, choose Duel Mode → 2-PLAYER DUEL → Data from your PC. Confirm your name, then choose Host to create a public room or Guest to find one. Internet is required for multiplayer.

Background music is off. Joey’s voice and game sound effects remain on.

Saves stay in this browser on this device. Save inside the game and use Save backup before clearing browser data. Closing the game during an online duel disconnects you.

This website runs the original executable. Initial loading and startup can take several minutes. Browser emulation is demanding, especially on phones; this website does not guarantee smooth mobile performance.
